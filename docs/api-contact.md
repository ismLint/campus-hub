### Формат передачи данных

JSON:
{
	  "id": 1,
  	"title": "Test Name",
  	"subject": "Test subjects",
  	"status": "todo",
  	"deadline": "2026-10-25T18:00:00Z"
}

### Статусы задач (`status`)

Поле `status` определяет текущее состояние задачи.

Допустимые значения:

| Значение      | Описание                               |
| ------------- | -------------------------------------- |
| `todo`        | Задача ожидает выполнения              |
| `in_progress` | Задача находится в процессе выполнения |
| `done`        | Задача завершена                       |

По умолчанию для новой задачи устанавливается статус `todo`.

При передаче неизвестного статуса API должен возвращать `400 Bad Request`.
